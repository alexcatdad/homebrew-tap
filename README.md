# Homebrew Tap

Homebrew formulae for [alexcatdad](https://github.com/alexcatdad) tools.

## Usage

```bash
brew tap alexcatdad/tap
```

## Formulae

<!-- BEGIN FORMULAE -->
| Formula | Version | Description |
|---------|---------|-------------|
| [paw-proxy](https://github.com/alexcatdad/paw-proxy) | 1.7.0 | Zero-config HTTPS proxy for local macOS development |
| [paw](https://github.com/alexcatdad/paw) | 0.3.0 | Personal dotfiles manager CLI |
<!-- END FORMULAE -->

### Install

<!-- BEGIN INSTALL -->
```bash
brew install alexcatdad/tap/paw-proxy
```
