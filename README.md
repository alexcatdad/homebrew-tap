# Homebrew Tap

Homebrew formulae for [alexcatdad](https://github.com/alexcatdad) tools.

## Usage

```bash
brew tap alexcatdad/tap
```

## Packages

<!-- BEGIN FORMULAE -->
| Formula | Version | Description |
|---------|---------|-------------|
| [paw-proxy](https://github.com/alexcatdad/paw-proxy) | 1.12.3 | Zero-config HTTPS proxy for local macOS development |
| [paw](https://github.com/alexcatdad/paw) | 0.5.0 | Personal dotfiles manager CLI |
| [pr-nanny](https://github.com/alexcatdad/pr-nanny) | macOS: 0.1.0-rc.6; Linux: 0.1.0-rc.5 | Passive GitHub pull-request monitor (signed macOS ARM64 cask, Linux x64 formula) |
| [scratchpad](https://github.com/alexcatdad/scratchpad) | pending first app release | Menu bar app for private developer memory (signed macOS ARM64 cask) |
| [scratchpad-mcp](https://github.com/alexcatdad/scratchpad) | 2026.10.1 (deprecated) | Replaced by the Scratchpad app cask |
| [usb-boop](https://github.com/alexcatdad/usb-boop) | 2026.09.17.5 | Menu bar app that reports negotiated USB link speed (cask) |
<!-- END FORMULAE -->

### Install

<!-- BEGIN INSTALL -->
```bash
brew install alexcatdad/tap/paw-proxy
brew install alexcatdad/tap/paw
# macOS ARM64
brew install --cask alexcatdad/tap/pr-nanny
# Linux x64
brew install alexcatdad/tap/pr-nanny
brew install --cask alexcatdad/tap/scratchpad
brew install --cask alexcatdad/tap/usb-boop
```
